Decisions baked in

The non-obvious calls and why they're worth defending in code review

Decision
Rationale
Risk
Burnt amber accent (#E59149) instead of category-standard cyan
Every direct competitor is cool-toned (Height cyan, Linear lavender, Granola green). Warm is absent and reads as deliberate taste. Connects to the voice/audio metaphor.
Might feel "sunset" if overused — that's why it's reserved to CTA + AI-active + focus only.
No glow / halo / "AI shimmer" on any AI state
Industry default (cyan halo) reads as Vegas casino. Replaced with a hairline-border pulse on the accent — quieter, faster to render, easier on the eyes.
Less immediately "look at me, I'm AI." Trades immediate signal for durable taste.
Instrument Serif on meeting summaries + analytics primary heading
The AI's output reads as a thought, not a chart label. Serif is the "writer's voice" cue. Strict scope (titles only) keeps the cost low.
Could read precious if it leaks into UI. Strictly title-only via a single `--font-serif` token used in 4 places.
13px body (not 14, not 16) + 4px-base spacing
Indie-hacker tools live dense. Linear, Height, and Raycast all cluster at 12-13px UI. Reads as "I respect your screen real estate."
Accessibility — we bump to 14px on `prefers-reduced-data` and the user-controllable density toggle in settings.
Inter Variable at weight 510 with cv01 + ss03 globally
Linear's exact recipe. Single-story 'a' + geometric alternates + mid-emphasis weight = engineered, not generic. Mandatory; never override.
Variable Inter is ~325KB self-hosted. Acceptable for first-party app; we preconnect to rsms.me on marketing.
Drop glassmorphism, neumorphism, gradients, magnetic hover, ripple
Existing DESIGN_SYSTEM.md is AI-slop manifesto. Real shipped CSS already drifted away from it. Make that drift official: hairline + elevation ladder + restrained motion.
Looks "less designed" to anyone reading from a 2020 Dribbble lens. That's the point.
